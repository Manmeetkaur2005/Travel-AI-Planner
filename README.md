# 🌍 AI Travel Planner ✈️

A smart travel itinerary generator powered by **Java Spring Boot** and **Google Gemini AI**.
This application creates personalized day-wise travel plans based on your destination, budget, and interests.

## 🚀 Features
- **AI-Powered Itineraries:** Generates detailed day-to-day plans using Google Gemini Pro.
- **Budget Estimation:** Calculates estimated costs for hotels, food, and activities.
- **Dynamic Suggestions:** Recommends hidden gems and local cuisines.
- **Clean UI:** Responsive web interface using HTML/CSS.

## 🛠️ Tech Stack
- **Backend:** Java (Spring Boot)
- **Frontend:** HTML, CSS, JavaScript
- **AI Model:** Google Gemini API
- **Build Tool:** Maven
